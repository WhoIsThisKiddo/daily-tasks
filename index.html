#!/usr/bin/env bash
LOG="/var/log/nginx/access.log"
if [[ -f "$LOG" ]]; then
    grep -Eo '([0-9]{1,3}\.){3}[0-9]{1,3}' "$LOG" \
    | sort \
    | uniq -c \
    | sort -nr \
    | head -n 10
else
    echo "Log file not found: $LOG" >&2
    exit 1
fi

A script grep-pel kivonja a logból az IPv4 címeket (grep -Eo), sorba rendezi (sort), megszámolja az ismétlődéseket (uniq -c), számszerű rendezést végez (sort -nr) és a leggyakoribb 10 találatot adja vissza (head). Cél: gyorsan megtalálni a legtöbbször előforduló IP-címeket egy access logban.

# Keresés AWS Access Key ID mintára (.log fájlokban)
$pattern = 'AKIA[0-9A-Z]{16}'
Get-ChildItem -Path . -Recurse -Filter *.log |
    Select-String -Pattern $pattern -AllMatches |
    ForEach-Object {
        foreach ($m in $_.Matches) {
            [PSCustomObject]@{
                File = $_.Path
                Match = $m.Value
                Line = $_.Line.Trim()
            }
        }
    } | Format-Table -AutoSize

A példában Get-ChildItem rekurzívan listázza a log fájlokat, Select-String regex-mintát alkalmaz (AWS Access Key ID jellegzetes prefixel: AKIA...), majd ForEach-Object és Matches segítségével kilistázza a fájlt, a talált kulcsot és a teljes sort. Cél: potenciális API/AWS kulcsok gyors felderítése a fájlokban.

Megoldás (regex):

\b[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\b

A regex három Base64URL-szerű részt keres, pontokkal elválasztva; minden rész legalább 10 karakter hosszú, így csökkenti a false positive-eket és alkalmas JWT-k azonosítására naplófájlokban (kereshető “Bearer ”, query-param vagy Authorization header esetén is).
